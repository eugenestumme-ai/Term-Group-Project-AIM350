# Clustering-Based Course & Study Recommendation Engine
**Course:** AIM 350: Programming for AI  
**Team:** Eugene Stumme, Shirley Santora, Sobaan Tariq, & Juan Pablo Mota  

## Project Overview
This project utilizes unsupervised machine learning (K-Means and Agglomerative Hierarchical Clustering) alongside Principal Component Analysis (PCA) to analyze student survey data, establish behavioral learner profiles, and deliver automated, personalized course recommendations (Microsoft Excel, Power BI, and Tableau).

## Repository Contents
- `aim350_course_recommender.ipynb`: The main Google Colab Jupyter Notebook containing data simulation, preprocessing pipelines, model evaluation metrics, and live inference scripts.
- `requirements.txt`: Required Python dependencies.

## Setup and Execution Instructions
To reproduce our results and run the interactive demo:
1. Clone this repository or download the `.ipynb` notebook.
2. Open the notebook in **Google Colab** (or a local Jupyter environment).
3. Ensure the required libraries listed in `requirements.txt` are installed:
